# DeudaMundi
DeudaMundi es una aplicación web que permite a los usuarios visualizar y analizar la deuda pública de diferentes países a lo largo del tiempo. La aplicación utiliza datos de fuentes confiables para proporcionar información precisa y actualizada sobre la deuda pública, incluyendo gráficos interactivos y tablas comparativas.
